# Infinite Connect Four

A modern, infinite-board twist on the classic Connect Four game, built with TypeScript and PixiJS.

## Getting Started

Follow these commands to set up and run the project locally:

1.  **Install dependencies:**
    ```bash
    npm i
    ```

2.  **Build the project:**
    ```bash
    npm run build
    ```

3.  **Run for development:**
    ```bash
    npm run dev
    ```

## Controls

### Keyboard
* **Move Selector:** Left/Right Arrow keys or `A`/`D` keys.
* **Pan Camera:** Up/Down Arrow keys or `W`/`S` keys.
* **Drop Piece:** `Space` or `Enter`.

### Pointer (Mouse/Touch)
* **Move Selector:** Hover or drag to move the selector.
* **Pan Camera:** Click and drag on the board to move the camera view.
* **Drop Piece:** Click/Tap on a column.

### Interface
* **Center View:** Use the "Center view" button to reset the camera to the origin.
* **New Match:** Click "New match" to clear the board and reset the game state.
